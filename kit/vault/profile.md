# Profile

Who this system is for. Gubernos and agents read the frontmatter:

- `name` — how agents address you; your log lines are written as your first name in lowercase.
- `language` — the language of task titles and documents agents write (chat replies follow the language you write in).
- `categories` — life areas for projects (the default five have colours in the app; others are grey).
- `workday` — Plan the day fits tasks between `start` and `end`, minus meetings and `lunch` minutes.
- `focus_time` — calendar events with this in the title are working time, not meetings.
- `assistant` — the name of a chat assistant that picks up its own agent tasks (e.g. `Cosy`); empty = none.
- `kit_version` — the version of the starter kit this vault was made from (for future updates).
